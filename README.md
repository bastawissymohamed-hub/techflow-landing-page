# TechFlow Systems - Landing Page

A sleek, high-performance, and modern responsive landing page built for a digital SaaS infrastructure platform. Designed using clean HTML5 semantic elements and standard modular CSS3.

Live Demo: [View Live Project](https://bastawissymohamed-hub.github.io/techflow-landing-page/)

---

## 🚀 Features

* **Top Announcement Bar:** Eye-catching banner for special promotions and announcements.
* **Modern Hero Section:** Clean introduction with clear Call-to-Action (CTA) buttons.
* **Services Grid:** Visual feature cards showcasing core solutions and technical services.
* **Pricing Plans:** Structured pricing cards highlighting the most popular option.
* **Interactive Plan Comparison:** Clean tabular presentation comparing features across plans.
* **Contact Form:** Structured input controls for potential client project inquiries.
* **Responsive Layout:** Flexbox-based layout adaptable across various desktop screen sizes.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic layout structure (`<header>`, `<main>`, `<section>`, `<table>`, `<form>`, `<footer>`).
* **CSS3:** Flexbox layouts, custom buttons, positioning, pseudo-elements (`::before`, `::after`), and forms styling.
